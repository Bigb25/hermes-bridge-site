Privacy Policy — Hermes Research Bridge

Effective October 16, 2026

Overview

Hermes Research Bridge is a personal, single-user application used by its developer to exchange genealogy research files between his own research software and his AI research assistant through Google Drive.

Data the application accesses

The application requests a single Google permission: drive.file (https://www.googleapis.com/auth/drive.file). With this permission the application can access only:

  • Files and folders it creates itself in the user's Google Drive, and
  • Files the user explicitly opens with, or shares to, the application.

It cannot list, search, or read any other files in the user's Drive. The application also receives the user's email address as part of the standard Google sign-in, used only to identify the account the user connected.

How the data is used

Accessed files are used solely to carry out the exchange the user set up: delivering research reports to the assistant and returning documented research findings to the user. No data is used for advertising, profiling, or any purpose unrelated to this exchange.

Storage

Files remain in the user's own Google Drive and on the user's own computer. The application stores its Google sign-in token on the user's own computer so the connection persists. The developer operates no external server that receives or stores the user's Drive data.

Sharing

Data accessed through Google APIs is never sold, rented, or shared with third parties.

Limited Use disclosure

Hermes Research Bridge's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Files stay in the user's Drive under the user's control and can be deleted by the user at any time. The user can revoke the application's access at any time from the third-party access page of their Google Account, which immediately ends the application's ability to reach any file.

Changes to this policy

If this policy changes, the updated version will be posted at this address with a new effective date.
